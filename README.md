# ✊✌️✋ 가위바위보 웹게임

간단하지만 살짝 심리전(?)이 들어간 가위바위보 게임입니다.
AI가 행동을 미리 보여주고, **70% 확률로 다른 선택을 하는** 트릭이 있습니다.

---

## 🎮 데모 설명

* AI가 먼저 "낼 예정인 행동"을 보여줍니다
* 하지만 실제로는:

  * **70% 확률로 다른 행동으로 변경**
  * 30% 확률로 그대로 유지
* 플레이어는 이를 보고 심리적으로 판단해서 선택

---

## ✨ 주요 기능

* 🎯 가위 / 바위 / 보 선택 버튼
* 🤖 AI 행동 예측 & 변경 로직
* 📊 실시간 점수 (승 / 패 / 무)
* 📜 게임 로그 기록 (최신순 표시)
* 💬 하단 랜덤 팁 (10초마다 변경)
* 🎨 글래스모피즘 UI + 부드러운 애니메이션

---

## 🧠 AI 로직

```javascript
if (Math.random() < 0.7) {
  // 다른 행동으로 변경
}
```

* AI는 일부러 혼란을 줌 😈
* "보여준 것과 다를 수 있다"가 핵심 포인트
